# Frontend agent entry point

For UI work in this app, read [design.md](design.md). It records the current identity, implementation map, theme contract, motion behavior, and demo boundaries.

Load the project-local skill matching the task:

- Build or change pages/components: [oya-frontend](.agents/skills/oya-frontend/SKILL.md).
- Add or tune animation: [oya-motion](.agents/skills/oya-motion/SKILL.md).
- Fix or review viewport layout, dark mode, or keyboard/touch behavior: [oya-responsive-theme](.agents/skills/oya-responsive-theme/SKILL.md).

These are portable Markdown instructions; read their paths directly if named skill discovery is unavailable. Read only the skills relevant to the requested work. Follow explicit user direction when it changes the documented design baseline.
